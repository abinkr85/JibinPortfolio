# Jibin Portfolio 🌐

A modern personal portfolio website built with HTML, CSS, and JavaScript. The site showcases Jibin Reji's professional profile, services, work, and contact information in a sleek single-page portfolio layout.

## Live Demo

- Website: https://abinkr85.github.io/JibinPortfolio/
- Repository: https://github.com/abinkr85/JibinPortfolio

## Overview

This portfolio website includes:

- A professional landing page with intro and profile section
- About Me section with background and skill overview
- Services section covering Mechanical Work, Graphic Design, and Digital Marketing
- Project showcase cards
- Contact form connected to Google Apps Script
- Social media links and downloadable CV
- Responsive design for desktop and mobile screens

## Tech Stack

- HTML5
- CSS3
- JavaScript
- jQuery
- Font Awesome
- Boxicons
- Typed.js
- ScrollReveal

## Local Setup

1. Clone the repository:

```bash
git clone https://github.com/abinkr85/JibinPortfolio.git
```

2. Open the project folder:

```bash
cd JibinPortfolio
```

3. Start a local web server:

```bash
python -m http.server 8000
```

4. Open your browser and visit:

```bash
http://localhost:8000
```

## Deployment

This project is configured for GitHub Pages and can be deployed directly from the repository.

## Customization

You can update the content by editing:

- `index.html` for home page content
- `about.html` for bio details
- `style.css` for layout and styling
- `javascript/script.js` for animations and interactivity
